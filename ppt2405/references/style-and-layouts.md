# 样式与页面选择

## 固定视觉体系

画布 16:9，1280×720 px（12192000×6858000 EMU）。模板一、三为主样式，保留白底、深蓝标题、蓝色结构区、清晰对齐和宽裕留白。默认沿用模板机构背景，只有用户指定另一机构时替换品牌资产；不要杜撰汇报人或机构。

| 用途 | 规则 |
|---|---|
| 主标题 | 微软雅黑、深蓝 `#0B4FA1`，常规 32pt |
| 面板小标题 | 微软雅黑，常规 19pt |
| 正文/结论 | 微软雅黑，常规 18pt，黑/深灰 |
| 数学 | Cambria Math，原生 Office 数学结构；变量也适用 |
| 英文摘要 | Times New Roman，保留模板摘要页层级 |
| 主色/辅助 | `#0056A5`、`#025FAD`；浅底 `#E0ECF9`，边线 `#ADC6E3` |
| 强调 | 少量 `#C00000` 红或 `#FFC000` 黄，含义一致 |

以上为常见层级，具体 slot 的 `fontSizePt`、允许范围和几何数据以 `layout-catalog.json` 为准。不要把封面、表格、条件说明和公式全部设为同一字号。标题过长优先短写或自然分行；正文太多优先精简/拆页，再小幅调节。避免单页局部极小字与大片空白并存。来源移至备注，页面不另加来源页脚。

## 正文的语义强调

有核心论断的正文页，先选观众应带走的结论，再将其中通常 1–3 组短语设为深红 `C00000` **并加粗**。优先选择核心结论、机制转折或同一实验条件下的对比数值，并能对应本页证据；其余正文保持常规黑/深灰，形成可辨的主次。强调以短语或数值为单位，不把整段染红，也不只靠标题粗体代替正文重点。封面、目录等没有正文论断的页面不强加红字。

在计划中先确定强调对象，再用普通文本 run 的 `color`/`bold` 或表格单元格样式写入，见组合接口。表格只强调正在讨论的关键格，页面保留指标方向与关键条件，完整来源放备注。数学仍保留原生结构和原有符号含义；优先强调旁边的中文解释，不为视觉强调擅自改变变量的数学粗体语义。

## 文字对齐与图形内位置

按文字的用途、行数和框宽选择对齐，字数只作参考；同一组并列图形保持一致，不用空格凑对齐。页面主标题沿用模板位置和对齐，不随正文规则改变。

| 内容 | 优先方式 | 调整依据 |
|---|---|---|
| 短标签、按钮式标题、少量文字的卡片 | 水平居中、垂直居中 | 与所属图形的视觉中心一致；两行以内按语义分行，避免孤字 |
| 较宽文本框中的多行中文正文 | 两端对齐，末行自然左对齐 | 正常字距下形成整齐边缘；窄框、短段或混排造成大空隙时改左对齐 |
| 英文正文、项目符号、定义列表 | 通常左对齐 | 保持词间距与各条起点一致，不为齐边拉伸单词 |
| 多段解释或较长正文 | 通常顶对齐 | 与相邻图的顶部或解释对象建立阅读顺序；短结论可在卡片中居中 |
| 表格、数字和公式 | 沿用相应模板 | 保持表头、列内数值和等式关系整齐；不把普通正文规则批量套入 |

在图形中调整文字时同时检查左右/上下内边距、换行后的视觉重心和边框距离。文字通常置于有效内容区中心；长段落需留出稳定的上缘和行距，不能为垂直居中挤压正文。左右装饰、图标或数学高符号会影响视觉重心，必要时在模板副本微调几何，随后看实际渲染。

组版对象用 `align` 与 `vertical_align` 显式指定，字段见组合接口；未指定时 helper 保留模板。先短写或拆页，再在槽位字号范围内适配，不能靠大幅缩字、缩到边框或强制分散对齐解决内容过量。两端对齐使用 `justify`，不用逐字分散来拉满最后一行。

这是一套页面库，不是固定26页的报告。常见研究汇报围绕任务—方法—实验—结论展开，但依据论文特点和用户大纲决定实际顺序。目录可少于/多于模板示例，必要时调整该页槽位布局或省略；不要把两大部分强加给每次汇报。

## 适配动作

每页先确定一件核心信息，再选择最合适的图文比例。原图过宽时用整图页或上下结构，过高时用纵向图文结构，多个子图不可为填充两个框而截断。能完整显示却看不清小字时，增加一页完整总览，再给明确标注的局部放大。

可微调内容框位置/尺寸，但保持模板的主标题位置、对齐线、边距、主色和字体层级。调整图片和文本时同步考虑解释距离与阅读顺序。原生表格不超出原框，长表分段并重复表头；空数据不以示例数字补足。

需要新布局时先由最接近的样例页改编，保留视觉体系。模板15、16、18的表格和25的示意图在样例页层级，必须复制整页；只用母版插入新页会遗漏这些对象。

## 内容驱动的版式调整

先看素材宽高比，再选框。宽图适合通栏，近方形/纵图适合大图加侧栏。图体只占图框中间一小块、两侧大量留白且图内字偏小时，换框形状或重新分配区域；禁止把“未裁切、未溢出”当作这一页合格的理由。长英文图注与图体分开处理，见图表提取说明。

完整架构首次展示后，后续页用明确标注的局部放大讲机制，避免反复缩放同一全图。时域与执行关系用原生时间轴，网络差异用对应架构对照；不要把所有机制都变成相同的五步流程卡片。连续页的布局变化应来自不同的信息关系。

真实任务页把机器人/观测/动作/关键数据条件与结果放在可见位置；详情和长协议进备注。演示视频与这些信息同页，PDF仍能从海报、关键帧和短结论读懂。视频与单次成功案例只说明行为，不替代统计表。小标签先用短词，必须换行时按语义分组，避免一个字单独落到第二行。红色只强调具体机制或关键数值，结果表可将讨论的值加粗/着色并说明口径。

### 需要改几何时

组版helper保留模板几何，不自动重排未知内容。可把内置PPTX和catalog复制到当前项目的 `build/template/`，在副本中修改相应命名slot的位置/尺寸，并同步catalog几何，重新计算两份SHA256，再通过 `--template/--catalog` 组版。布局上的边框、面板标题、连接线与相邻内容须同时适配；只移动图片会留下旧框。也可在组版后以可重复脚本进行有记录的几何调整，随后验证关系、公式/表格、文本边界并完整渲染。保持主标题、蓝白配色、字体层级与左右边距。不要就地改skill内置模板，或把本篇论文的答案写入通用模板。

本版的版面对象都在普通幻灯片上。复制样例页后，在“选择窗格”选中内容框、相邻底板和标签一起移动。连接线和独立标签也可单独删除。替换图后按实际投影尺寸读一次图例；若仍太小，可缩短侧栏说明，将腾出的空间留给图。

对改变位置或尺寸的文本框，重新核对继承的左右、上下内边距（`lIns/rIns/tIns/bIns`），按新框尺寸减去内边距计算有效文字区域。旧内边距过大时，在项目副本中显式设置合适值，再做字体测量与原生渲染检查；保留文字与框线的必要间隔，不把所有文本框统一设为零内边距。
