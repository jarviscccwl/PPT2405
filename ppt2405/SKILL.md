# ppt2405

在独立项目目录中制作中文学术汇报。资源路径相对本文件；`assets/ppt2405.pptx` 提供 26 张普通样例页，可按内容复制、调整和排序。页数由汇报目的、时长和证据量决定。

## 从输入确定任务

| 用户提供 | 从哪里开始 |
|---|---|
| 一篇或多篇文献 | 读正文、图表和局限，提取问题、方法、比较条件及结果。多篇文献按共同问题组织，标清各自证据。 |
| 大纲、主题或笔记 | 保留指定章节；只有主题时先拟提纲。把每节拆成听众需要回答的问题，检索支撑材料，再确定能讲到什么程度。 |
| 大纲和文献 | 用大纲决定顺序，把文献中的证据映射到各节；对仍缺依据的主张补查一手来源。 |
| 已有 PPT | 按用户指定范围修改，核对受影响页及引用。 |

## 制作与交付

1. **收集资料。** 从用户材料出发，针对缺口查原论文、官方项目或数据发布方。打开原文核对数字、单位、实验条件和出处。无法核实的主张标为待验证或省略。项目记录方法见[研究与素材](references/research-and-assets.md)。
2. **逐页规划。** 每页写一句核心信息，配上证据、素材、版式和讲解要点。方法页说明机制及适用条件；结果页并列可比数据；结论交代边界。按图的宽高比选择[页面版式](references/style-and-layouts.md)。
3. **准备图像。** 实证页使用原图、原始数据或现场资料；PDF 图按[提图说明](references/figure-extraction.md)保留全部面板、轴和图例。概念或场景页按需要调用图像生成工具，检查图意，并在页上注明“AI生成示意图，非论文原图”。无生图工具时可改用 PPT 原生示意图。
4. **组版。** 按[组合接口](references/composition-api.md)和[槽位目录](references/layout-catalog.json)编写计划，用 `scripts/compose_deck.py` 的 `strict` 模式生成。保留可编辑文字、原生公式和表格。重点短语深红加粗，图片等比放置；来源写入该页备注。
5. **交付。** 按[交付检查](references/quality-and-delivery.md)逐页渲染复核。默认交付可编辑 PPTX、PDF 预览和来源清单；用户指定格式时以其要求为准。
